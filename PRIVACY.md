# SimpleRemote privacy policy

_Last updated: 7 November 2026_

SimpleRemote is an infrared remote control app. It turns your phone's built-in IR blaster into a
remote for air conditioners, TVs, fans, projectors and other devices.

## Summary

- No account, no sign-in, no ads, no analytics or tracking SDKs.
- Your saved remotes and their settings stay on your phone.
- The app works fully offline.

## Data stored on your phone

The app stores the remotes you add (name, device type, brand, code set and the last state you set,
such as AC temperature) and your home-screen widget choices. This data never leaves your phone,
except through Android's own device backup if you have it turned on. Uninstalling the app deletes it.

## Optional anonymous code statistics

Some versions of the app may ask whether you want to share anonymous code test results. This is
**off unless you say yes**, and the question only appears in versions that have a statistics server
configured. If you agree, each time you test a code during setup the app sends:

- device type, brand and code-set id, and whether the code worked;
- your phone's manufacturer and model, Android version and app version;
- a timestamp.

It does **not** send your name, remote names, an account or advertising id, an install id, your
location or your contacts. The results are used only to show which codes work best, so they can be
offered first. You can turn this off at any time in **About → Share anonymous code results**, which
also deletes any results that have not been sent yet.

## Permissions

- **Transmit infrared** (`TRANSMIT_IR`): to send remote control signals.
- **Internet**: used only for the optional statistics above. The app does not download ads or content.

## Children

The app is not directed at children and does not knowingly collect personal information from anyone.

## Changes

If this policy changes, the new version will be posted here with a new date.
